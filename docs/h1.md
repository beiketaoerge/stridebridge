# H1 lineage

The foundation is the workspace's `0927_real_deploy` controller as it existed on
2026-10-10. [Source hashes](h1_source_manifest.json) record that baseline.

`examples/h1_latest/` preserves the controller, original switcher, coordinated
left-leg assist, native DDS simulation runner and 25 operator regressions.
Executable path changes resolve bundles through `assets/local/h1/0927` and
`assets/local/h1/0823`; controller logic is unchanged. The public simulation
package extracts the same DWAQ and motion adapters with per-instance options,
avoiding hardware initialization. A 160-sample synthetic-feedback replay checks
exact observation/command equivalence against the preserved adapter classes,
including the assisted motion frames. That test checks implementation equivalence,
not physical performance.

The first public demo is deliberately a flat-ground switching task. It retains
the native H1 robot and learned motion, and disables/removes the board collision
and rendering. Initial position, quaternion and joint pose come from reference
frame 0; hardware startup is outside this simulation. No root constraints,
elastic support, pose resets during motion or gravity support forces are applied.

The prior workspace's obstacle-distance evaluation remains a separate result:
38/50 trials met its primary crossing-and-standing criterion and 32/50 met its
stricter continuous-crossing criterion. Two runs triggered post-handoff tilt
protection. Those historical results were reported in
`0927_real_deploy/validation/board_distance_10each_20261003/TEST_REPORT.md` and
were not rerun for this release. They must not be replaced by the new flat-ground
demo's success counts.

The hardware snapshot still requires the original SDK environment and imported
base controller/common helpers. Its 25 offline operator regressions use synthetic
feedback and do not initialize DDS. The public default commands only run MuJoCo.
Current hardware stability has not been established by this release.
